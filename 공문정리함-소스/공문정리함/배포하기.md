# 배포하기

파이썬이 없는 컴퓨터에 나눠 주려면 윈도우용 실행 파일이 필요합니다.
그런데 실행 파일은 **윈도우에서만 만들 수 있습니다.** PyInstaller는 다른
운영체제용 파일을 만들지 못합니다.

윈도우 컴퓨터가 없거나 파이썬을 깔기 싫으시면 아래 1번 방법을 쓰세요.

---

## 1. GitHub이 대신 만들게 하기 (권장)

내 컴퓨터에는 아무것도 깔지 않습니다.

1. GitHub에 새 저장소를 만들고 이 폴더 전체를 올립니다.
   `.github` 폴더가 빠지면 안 됩니다. 숨김 폴더라 놓치기 쉽습니다.
2. 저장소 위쪽 **Actions** 탭 → 왼쪽에서 **윈도우 설치 파일 만들기** 선택
   → 오른쪽 **Run workflow** 버튼
3. 5분쯤 뒤 초록 체크가 뜨면, 그 실행 결과 화면 맨 아래
   **Artifacts** 에서 `gongmun-windows` 를 내려받습니다.
4. 압축을 풀면 파일 세 개가 나옵니다.

| 파일 | 쓰임 |
|---|---|
| `공문정리함-설치.exe` | 나눠 줄 때 이걸 주면 됩니다 |
| `공문정리함.exe` | 설치 없이 바로 실행. USB용 |
| `사용설명서.txt` | 같이 주세요 |

버전을 매겨 두고 싶으면 태그를 올리면 됩니다. 자동으로 Releases에
올라가서 링크 하나만 주면 되는 상태가 됩니다.

```
git tag v1.0.0
git push origin v1.0.0
```

## 2. 윈도우 컴퓨터에서 직접 만들기

파이썬 3.10 이상이 깔린 윈도우가 있으면 명령 프롬프트에서

```
pip install -r requirements.txt pyinstaller
pyinstaller --clean --noconfirm 공문정리함.spec
```

`dist\공문정리함.exe` 가 나옵니다.

설치 프로그램까지 만들려면 [Inno Setup](https://jrsoftware.org/isdl.php)을
설치한 뒤

```
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer.iss
```

`dist\공문정리함-설치.exe` 가 나옵니다.

## 나눠 줄 때 꼭 알려 주실 것

**파란 경고 창이 뜹니다.** 서명 인증서를 사지 않은 프로그램이라
윈도우가 "Windows의 PC 보호" 창을 띄웁니다. 바이러스 판정이 아니라
"누가 만들었는지 확인이 안 된다"는 뜻입니다.

받는 분께 이렇게 알려 주세요.

> 파란 창이 뜨면 왼쪽 아래 **추가 정보**를 누르세요.
> 그러면 아래에 **실행** 단추가 나타납니다.

이 안내를 빠뜨리면 대부분 여기서 포기합니다. 사용설명서 맨 앞에도
같은 내용을 적어 두었습니다.

메신저나 메일로 exe를 그냥 보내면 차단되는 경우가 많습니다.
GitHub Releases 링크를 주시거나, 학교 업무용 클라우드에 올려 두고
주소를 알려 주시는 편이 확실합니다.

**백신이 잡을 수 있습니다.** PyInstaller로 만든 서명 없는 exe는
V3나 알약이 가끔 오탐합니다. 배포 전에 한 대에서 먼저 확인해 보시고,
잡히면 해당 백신 회사에 오탐 신고를 넣으면 며칠 안에 풀립니다.

## 설치되는 곳

관리자 권한을 요구하지 않도록 사용자 폴더에 설치됩니다.
학교 컴퓨터에서 권한이 막혀 있어도 설치됩니다.

```
설치 위치   C:\Users\(사용자)\AppData\Local\Programs\공문정리함
기록 위치   C:\Users\(사용자)\.gongmun
```

## 고쳐서 다시 배포할 때

`installer.iss` 위쪽의 `AppVersion` 과 `version.txt` 의 버전을 함께
올려 주세요. `AppId` 는 바꾸지 마세요. 이 값이 같아야 새로 설치할 때
예전 것을 덮어씁니다.
