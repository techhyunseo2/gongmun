결재 전후 비교하기

결재자가 말없이 고친 따옴표나 글자 하나를 찾아 줍니다.

  1. 원본과 결재된 문서를 같은 확대 배율로 나란히 띄웁니다.
  2. 작은 창의 초록·빨강 사각형 아이콘 → 비교 시작.
  3. 화면이 살짝 어두워지면 원본 쪽을 드래그합니다.
  4. 이어서 수정본 쪽을 드래그합니다.

달라진 자리가 빨간 상자로 표시됩니다. 글자가 아니라 화면 모양을 견주므로 한글이든 PDF든 됩니다.

똑같은 파일을 또 받은 경우에만 중복 파일을 휴지통으로 보내며, 되살릴 수 있습니다.

이런 경우는 잘 안 됩니다

  • 스캔한 PDF(글자가 아닌 그림)와 암호가 걸린 파일은 읽지 못합니다. 목록에는 뜨지만 미분류로 들어갑니다.
  • hwp 파일은 표 안의 글자가 빠질 수 있습니다. 한글에서 다른 이름으로 저장 → hwpx로 바꿔 두면 가장 정확합니다.
  • 업무 종류와 기한은 문장 규칙으로 판단하므로 틀릴 수 있습니다. 근거가 약하면 확인 필요 표시가 붙고, 고친 값이 항상 우선합니다.

막히셨나요?

작은 창이 사라졌어요

바탕화면 보기를 누르거나 다른 창에 가리면 작은 창이 숨습니다. 이 창은 작업 표시줄에 뜨지 않습니다.

바탕화면이나 시작 메뉴의 공문 정리함을 한 번 더 누르세요. 두 개가 뜨는 것이 아니라 숨어 있던 창이 앞으로 나옵니다.

새로 받은 공문이 목록에 안 보여요

10분마다 폴더를 다시 훑습니다. 바로 보고 싶으면 다시 훑기를 누르세요. 작은 창의 폴더 표시를 눌러, 공문을 저장한 폴더와 같은지도 확인해 주세요.

기한이나 업무 종류가 틀렸어요

전체 화면에서 직접 고치면 고친 값이 항상 우선합니다. 기한이 비어 있으면 본문에 나온 날짜에서 맞는 날짜를 누르세요.

업데이트는 어떻게 하나요?

따로 하실 일이 없습니다. 새 버전이 나오면 알려 주고, 예를 누르면 알아서 받아서 바뀝니다. 바로 확인하려면 작은 창에서 마우스 오른쪽 버튼 → 업데이트 확인.

컴퓨터를 켤 때 자동으로 띄우고 싶어요

윈도우 키 + R → shell:startup 입력 → 열린 폴더에 바탕화면의 공문 정리함 아이콘을 마우스 오른쪽 버튼으로 끌어다 놓고 여기에 바로 가기 만들기. 끄려면 그 바로가기를 지우면 됩니다.

지우려면 어떻게 하나요?

윈도우 설정 → 앱 → 공문 정리함에서 지웁니다. 설정과 처리 기록도 지울지 한 번 묻는데, 아니오(기본)를 누르면 다시 설치했을 때 이어서 쓸 수 있습니다. 어느 쪽이든 공문 파일은 지워지지 않습니다.

설치하지 않고 쓸 수 있나요?

네. gongmun.exe를 바로 실행해도 똑같이 동작합니다. USB에 넣어 다녀도 됩니다.
